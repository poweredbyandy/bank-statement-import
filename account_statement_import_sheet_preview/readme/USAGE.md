1. Abra el diario bancario e inicie la importación de extracto.
2. Suba un archivo TXT, CSV o XLSX.
3. El asistente detecta el formato y actualiza la vista previa automáticamente.
4. Revise el bloque **Así se verá en Odoo**.
5. Si hace falta, ajuste las columnas o active **Opciones avanzadas**.
6. Pulse **Importar extracto**.

Con **Recordar este formato la próxima vez** activado (por defecto), el formato
se guarda al importar y queda como último usado del diario.
